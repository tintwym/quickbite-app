QuickBite — User Stories
As a new user, I want to sign up with a username, email, and password, so that I can create an account and access the app.
As a returning user, I want to log in with my email and password, so that I can access my saved data.
As a user, I want to see a clear error message if my signup fails (e.g. missing field or duplicate email), so that I know what went wrong.
As a user, I want to see a clear error message if my login fails (e.g. wrong password), so that I know why I couldn't log in.
As a user, I want to see a home screen with a list of recipes and the app logo in the header, so that I can browse what's available.
As a user, I want to tap a recipe to view its detail screen, so that I can see ingredients and instructions.
As a user, I want to save recipes as favorites, so that I can find them again later without searching.
As a user, I want my favorites to persist locally on my device, so that they're still there when I reopen the app.
As a user, I want to access a settings menu where I can adjust notification preferences, so that I can control how the app contacts me.
